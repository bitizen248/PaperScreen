# PRODUCT.md

Product definition for the portable productivity tool.

## Vision

A calm portable e-paper device for personal productivity: tasks, reading, focus sessions, and an optional desk display mode.

## Core use cases

- Capture and review tasks
- Read long-form text without a bright screen
- Run focus timers
- Show ambient desk information while idle or docked

## Primary user experience goals

- Low distraction
- Quick resume
- Clear typography
- Minimal taps
- Strong battery life
- Works offline first

## Feature priorities

### V1

- Home screen
- Tasks: inbox, today, done
- Focus timer: start, pause, resume, history-lite
- Desk-board mode with clock, next task, current timer, battery
- Settings for sleep, refresh, and theme density
- Persistent local storage

### V2

- Reader for TXT / Markdown
- bookmarks and resume position
- Wi-Fi sync
- import/export

### V3

- EPUB support
- optional LoRa summaries or relay features
- richer desk-board widgets

## UX rules

- One-tap actions should dominate
- Gestures should be simple and discoverable
- Reader should use page turns, not kinetic scrolling
- Timer should remain legible at a distance
- Desk-board mode should favor contrast and large layout blocks

## Constraints

- E-paper refresh is precious
- Touch exists, but not for dense tiny controls
- Network may be unavailable
- The product should still be useful with no phone nearby

## Success criteria

The product succeeds when it can spend most of the day in one of three stable states:
- task board
- reading session
- focus / desk mode

without feeling like a general-purpose gadget.
